# Развёртывание: одна ссылка для всех устройств

Нужен **HTTPS**: без него в браузерах не работают офлайн-кэш сайта (service worker), камера и гироскоп.
Файл `index.html` двойным щелчком открывать нельзя — нужен запущенный `server.js`.

## Вариант A. Быстро, для показа и теста с телефона (со своего компьютера)

Компьютер с сервером должен быть включён, пока ссылкой пользуются.

1. Запустите сервер: `node server.js` (окно оставьте открытым).
2. Во втором окне PowerShell установите и запустите туннель Cloudflare:
   ```
   winget install Cloudflare.cloudflared
   cloudflared tunnel --url http://localhost:3000
   ```
   (после установки откройте новое окно PowerShell). В выводе будет адрес вида `https://что-то.trycloudflare.com` — это и есть ваша ссылка. Её открывайте на всех устройствах, в том числе и на компьютере: ссылки «Поделиться» берут адрес, с которого открыт сайт.
3. Адрес **меняется при каждом запуске туннеля**, поэтому старые ссылки «Поделиться» перестанут открываться. Для постоянной ссылки нужен вариант B.

Альтернатива туннелю — ngrok (нужна бесплатная регистрация): `ngrok http 3000`.

## Вариант B. Постоянно: сервер (VPS) + домен

Нужны: VPS с Ubuntu (22.04 или 24.04, от 1 ГБ памяти), домен или бесплатный поддомен (DuckDNS), направленный A-записью на IP сервера, открытые порты 22, 80 и 443.

1. **Домен → IP сервера.** Проверка в PowerShell: `nslookup maps.example.com` должен показать IP VPS.
2. **Подключиться и установить Docker** (на сервере):
   ```
   ssh root@IP_СЕРВЕРА
   curl -fsSL https://get.docker.com | sh
   ufw allow OpenSSH && ufw allow 80/tcp && ufw allow 443/tcp && ufw allow 443/udp && ufw enable
   ```
3. **Загрузить проект** (на своём компьютере, PowerShell). Перед этим удалите из папки проекта `data` (локальные тестовые аккаунты) и старый `.env`, если он есть:
   ```
   scp -r D:\Downloads\files\spacemap root@IP_СЕРВЕРА:/root/
   ```
4. **Указать домен** (на сервере):
   ```
   cd ~/spacemap
   echo "DOMAIN=maps.example.com" > .env
   ```
5. **Запустить:**
   ```
   docker compose up -d --build
   docker compose ps
   docker compose logs -f caddy      # ждите строку про выданный сертификат; выход — Ctrl+C
   ```
   Сайт откроется по `https://maps.example.com`.

Дальше (все команды — из папки `~/spacemap`, `DOMAIN` берётся из `.env`):

- Обновление: загрузить изменённые файлы тем же `scp`, затем `docker compose up -d --build`. Данные (аккаунты, карты) лежат в томе `appdata` и сохраняются.
- **Не выполняйте `docker compose down -v`**: флаг `-v` удаляет том с данными.
- Резервная копия: `docker compose cp app:/data ./backup`, затем скачайте папку на компьютер через `scp -r`.
- Логи: `docker compose logs -f app`.

Без Docker: `node server.js` под systemd или PM2 и Caddy с файлом
```
maps.example.com {
	reverse_proxy localhost:3000
}
```

## Что проверить после запуска

1. `https://ВАШ-АДРЕС/api/ping` отвечает `{"ok":true,...}`.
2. Регистрация и вход работают, карта создаётся, «Поделиться» даёт ссылку с вашим адресом.
3. Ссылка открывается на другом телефоне. После первого открытия включите режим «в самолёте» и обновите страницу: карта и панорамы должны открыться.
4. Код из «Поделиться → Встроить на сайт» вставьте в любую HTML-страницу — карта показывается без шапки и только для просмотра.

## Как работает «без интернета»

- Первое открытие ссылки требует интернета: карта и панорамы скачиваются в браузер, сайт кэшируется.
- Дальше та же ссылка открывается без сети в том же браузере. Safari на iPhone может очищать данные сайтов, которыми давно не пользовались: надёжнее добавить сайт на экран «Домой» либо выдать посетителям офлайн-файл (`Поделиться → Офлайн-версия`) — он работает всегда.

## Настройки (.env, необязательно)

`PUBLIC_URL` — публичный адрес (в варианте B задаётся автоматически), `EMBED_ORIGINS` — список сайтов, которым разрешено встраивать карту (по умолчанию любые), `DATA_DIR` — папка данных. Пример — в `.env.example`.
